# Keymaster

Keymaster 是本地优先的 BSV 浏览器钱包。它提供钱包身份、签名、加密、资产、消息、文件及外部 App 授权能力。

钱包数据保存在当前浏览器、当前站点的本地 IndexedDB 中。同一浏览器配置和站点保存一把钱包 Key；首次使用可创建或导入，日常使用通过密码解锁。

## 使用

打开交付方提供的 Keymaster 地址，按初始化向导创建或导入钱包。已初始化的钱包启动后进入锁定状态，输入钱包密码解锁。

[钱包使用说明](docs/使用说明.md) · [安装与部署](docs/安装与部署.md)

## 项目结构

主应用入口位于根目录 `src/`，静态文件位于 `public/`，运行时与功能插件位于 `packages/`。根目录统一管理应用依赖、版本和开发构建命令。

边测和集成测试由同级 `BSV8_Engineering` 仓库维护，测试专用页面钩子、夹具和构建配置也位于该仓库。

## 自行部署

使用 Node.js 22 和 pnpm 11.5.1，在项目目录执行：

```bash
pnpm install --frozen-lockfile
pnpm build
```

应用静态产物位于 `dist/`。将它部署到支持单页应用路由的 HTTPS 站点，保留随产物提供的响应头和路由配置。完整步骤见[安装与部署](docs/安装与部署.md)。
