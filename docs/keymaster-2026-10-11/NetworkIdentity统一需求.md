# NetworkIdentity 统一需求

状态：本地实现与自动化验收已完成；真机与线上通信验收尚未执行。

## 最终语义

取消全局 testnet 环境开关。身份统一为 `NetworkIdentity = { bsvNetwork: "main" | "test"; publicKeyHex: string }`。生成或导入私钥时明确网络，作为身份不可变归属；私钥本身不能推断网络。公钥仍是密码学验签材料，业务身份比较必须同时比较网络。

当前产品为单 Key 钱包：身份建立后不能修改网络。需要另一网络时走明确的重置和创建/导入流程。初始化、解锁、改密、改名、软硬件迁移必须保存同一网络。KeyHold 是标准私钥文件：导入后由 Keymaster 附加网络；导出标准 KeyHold 时去掉网络属性。Rockey 在设备内保存网络＋私钥，公开接口仅暴露 NetworkIdentity。

## 跨模块边界

Keymaster 在任何业务启动前恢复完整身份。插件、Connect SDK、Rockey 统一绑定该身份。广播、事件、授权、任务、缓存和异步结果的归属包含网络；旧会话不能跨身份复用。

P2PKH 删除 includeTestnet 设置和双网同时运行语义。只显示、同步和花费当前身份网络的资产。显式指定另一网络的交易请求必须拒绝；未指定网络的业务使用身份网络。

SS/SatSubscription 内置主网服务器为 us-gateway.bsv8.com，测试网为 ustest-gateway.bsv8.com。网络选择由身份派生，删除 DEV 选择网关和 VITE_BITFS_NETWORK 选择业务网络的逻辑。自定义供应商、通讯订阅、SPI 账户、BitFS 及其他业务配置均位于身份存储空间。

Connect SDK 初始化传入完整 NetworkIdentity，握手及业务会话返回完整身份并验证网络和公钥同时一致。SDK 无权修改钱包网络。签名协议中的网络归属必须被认证，不能依赖可修改的外部路由字段。

Rockey 创建/导入时保存网络，连接时验证网络与公钥。已有身份不能通过 update 改网；update 仅同步或验证同一身份。付款/签名核对身份网络，软硬件迁移保留归属。

## 存储

所有身份/业务存储由平台统一绑定根：`<bsvNetwork>/<publicKeyHex>/<模块或 apps/...>/...`。文件、数据库键、缓存及持久化任务记录遵循同一原则，插件仅提供相对路径。

固定 key.json 和钱包冷启动元数据作为身份发现入口，可以位于根目录；Key 记录必须明确保存网络；发现元数据仅管理初始化状态与世代，不复制第二份网络真值。业务数据不能落入无网络前导的旧目录。句柄绑定完整身份及钱包/会话/运行世代，迟到结果不能访问另一身份空间。

旧钱包和数据不能根据 DEV、includeTestnet 或当前选择自动猜测归属。无网络记录严格拒绝运行并提示需要明确归属升级；不静默删除旧数据、不保留业务读取旧根的回退路径。

## 验收

1. 主网/测试网创建、导入后，锁定、重启、改密、改名和软硬迁移保持相同身份。
2. 同一公钥的主网和测试网存储根不同；不能读写对方数据。
3. 当前身份决定地址、可见资产、链同步、SS 服务器和 BitFS；开发/正式构建无权改网。
4. SDK、Rockey 或业务请求网络不一致时，在签名/付款/通讯前拒绝。
5. 广播和生命周期快照可识别完整身份；会话和旧异步结果不能跨网络复用。
6. 删除原 includeTestnet 产品设置及旧双网运行逻辑。真实组件/存储/密码学测试验证边界，不使用虚假实现。

## 实施记录

### 身份与私钥

`packages/contracts/src/networkIdentity.ts` 提供统一网络类型、身份校验、完整身份比较和存储前导。Vault 的创建草稿、KeyRef、KeyIdentity、冷启动摘要与解锁结果携带 `bsvNetwork`。创建/导入界面一次性选网；现有身份没有改网入口。锁定不改变已存身份，解锁时恢复相同归属。

本地软件 Key 文件使用 `keymaster.network-keyhold` v1 封装：标准 KeyHold + `bsvNetwork` + 私钥 HMAC 认证的网络归属。解密后验证网络、公钥一致，篡改网络不得解锁。导出仍为标准 KeyHold，移除本地网络与认证字段。改名/改密码与迁移沿用原网络。

Rockey KeyStore 封装升级为 v2，网络进入 AES-GCM AAD；PIN 更新不能改网。同公钥不同网被视为不同身份，设备拒绝直接覆盖。设备恢复备份升级为 v2，携带并认证网络，恢复保持完整身份。旧无网络封装不自动猜测归属。

### 存储与业务

平台 Root 在装配时冻结完整身份。所有业务文件/K-V/快照和付款账本位于 `<network>/<pub>/...`。授权绑定相同网络、公钥及钱包/会话/运行世代；App 会话网络不一致不能获得存储授权。删除和垃圾回收仅操作已绑定身份根。

根目录的 `key.json`、钱包发现元数据与公开迁移日志是受限的引导例外；迁移日志明确记录网络。迁移付款账本使用身份前导，迁移保存业务目录，不能以无网络根回退读取旧账本。

P2PKH 的 `includeTestnet` 设置与双网菜单已删除。网络展示由身份投影，费用与供应商偏好不能修改身份网络。地址、UTXO、余额、历史、BSV-21 与 1Sat 查询只使用身份网络；显式指定另一网的交易和付款渠道被拒绝。STAS 保持现有主网支持范围，test 身份不能借用主网资源。

SS 默认网关与 BitFS 网络从身份派生。开发模式不再决定业务网络。开发环境的 loopback 传输许可仍属于本地调试能力，不修改身份归属。远程协议中的原始公钥仍用于验签/ECDH，业务归属由当前完整身份、相应网络网关及身份存储共同约束。

生命周期与业务 Topic 广播包含完整身份；后台任务 scope、资产通知合并/过滤、App 会话及存储授权均同时核对网络与公钥。旧任务按启动身份取消，迟到结果受完整身份与世代栅栏约束。

### Connect 与硬件边界

Connect SDK 初始化必填完整 `networkIdentity` 并冻结其副本。请求、回复和事件携带完整身份；登录/恢复/启动结果中的身份也须与客户端约束一致。`ready` 仅代表浏览器传输就绪。SDK 不提供改网操作。

浏览器外层 Connect 消息继续使用 v1；签名 Identity/Intent 的 CBOR envelope 升级为 v2，加入受签名保护的网络。cipher 的站点域分离升级为 `keymaster:cipher:v2|<network>|<origin>`，同公钥不同网络不能复用站点密钥。旧签名 envelope/无网络客户端不能继续作为完整身份调用。

VaultLink `identity.network` 查询返回设备完整公开身份。Keymaster 连接/登记设备时验证网络及公钥，迁移配对时核对所选网络，迁移完成前校验源私钥的设备持有证明。空设备的配对用临时传输公钥不得写为钱包身份。软件和硬件付款核心接收不可变网络，并拒绝另一网络的渠道/账本。

底层 VaultLink 源码同步修改于相邻 `BSV8_VaultLinkProtocol` 仓库；Keymaster/Rockey vendor manifest 保留原 sourceCommit，并用 sourceOverlay 记录本地修改文件的基线与当前 SHA-256，未伪造上游提交。

### 兼容边界

本次是身份与存储格式的硬升级，不保留无网络身份的自动 main 回退。现有无网络钱包会明确拒绝运行并保留原记录；恢复时应先保留原私钥备份，再经明确创建/导入流程指定网络。不会静默移动、删除或自动归类旧业务数据。旧数据的人工归属迁移界面不在本次实现范围内。
