# 安装与部署

## 直接使用

打开交付方提供的 HTTPS 地址。首次使用按钱包初始化向导操作；之后在同一浏览器配置和同一站点中解锁钱包。

## 从源码构建

准备 Node.js 22 和 pnpm 11.5.1，在 Keymaster 项目目录执行：

```bash
pnpm install --frozen-lockfile
pnpm build
```

依赖安装遵循项目锁文件。构建成功后，应用文件位于 `dist/`。

## 本机预览

```bash
pnpm preview --host 127.0.0.1 --port 4173
```

浏览器打开 `http://127.0.0.1:4173/`。这是本机预览入口，部署时使用静态产物。

## 部署与更新

将 `dist/` 的内容部署到支持单页应用路由的 HTTPS 静态站点，保留产物中的响应头和路由配置。更新时替换应用静态文件，保持原站点地址；钱包本地数据不会自动转移到新的浏览器配置或站点。
